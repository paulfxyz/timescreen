THE WHOLE SCREEN

A little more room.

Use native fullscreen, or install this page as a home-screen app.

iPhone & iPad

In Safari, open Share, choose Add to Home Screen, and enable Open as Web App if shown. Launch the new Time icon to remove browser controls.

Apple’s step-by-step guide

Android

Use Enter full screen, or choose Install app / Add to Home screen in your browser menu. Open the installed Time icon for a dedicated display.

Desktop & TV browsers

Use Enter full screen or press F. If your browser restricts it, use its own fullscreen command, usually F11 on Windows/Linux or Control + Command + F on a Mac. TV browsers may use their own display menu.

Websites cannot override browser or operating-system restrictions. In display mode, the page fills the available viewport; only native fullscreen or a home-screen app can remove browser controls.
